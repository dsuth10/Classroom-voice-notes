# Gate C Governance Checklist

Complete Gate C only after Gate B staging evidence is accepted. This is a
governance approval record, not an automated test result. It must be completed
before any real classroom information is enabled for outbound sharing.

| ID | Required approval or operational control | Accountable owner | Evidence reference | Approval date | Status |
|---|---|---|---|---|---|
| GOV-01 | Privacy/data-impact assessment is approved for the intended school and jurisdiction. | Privacy owner | | | Pending |
| GOV-02 | Legal basis, notice/consent model, and processor agreements are confirmed. | Legal/privacy owner | | | Pending |
| GOV-03 | Transcript inclusion and retention are explicitly approved. | Data owner | | | Pending |
| GOV-04 | Production secrets and rotation owners are established. | Security owner | | | Pending |
| GOV-05 | Worker hosting and on-call owner are established. | Operations owner | | | Pending |
| GOV-06 | Backup/restore, deletion, correction, and audit-request procedures exist. | Operations/data owner | | | Pending |
| GOV-07 | User-facing controls pass accessibility and comprehension review. | Product/accessibility owner | | | Pending |
| GOV-08 | Support and incident-response owners are named. | Support owner | | | Pending |

Gate C is complete only when every row has evidence, an accountable owner, and
an approval date. Any exception requires an explicitly documented risk
acceptance by the designated authority.
